# 法律技能一键部署与切换方案

本仓是**法律技能的唯一部署入口**（对外 Public），只部署与加载法律技能，与其他技能仓互不包含。

## 方案概览

34 个法律技能仓都是 SKILL.md 技能包（不是 MCP 服务器），AI 客户端无法用 MCP JSON「安装」它们。因此分两层：

1. **一键部署**：按 GitHub topic `wife-legal` 自动发现组织 `aukodeng-skill` 下的法律仓，仓名清单不写死；`catalog.tsv` 把它们按 10 个业务分类登记，支持按分类 / 按仓库 / 全部三种选法。
2. **按需切换**：
   - **技能层（推荐）**：`--action enable` 只把选中的仓库平铺进项目 `.trae/skills/`，不选的就不复制——这就是「切换」。`--action disable` 反向移除。
   - **MCP 层**：`workbuddy-mcp.json` 配置 filesystem MCP 指向技能库根目录，按需读取任意 SKILL.md，不占常驻上下文。

## 平台支持

`deploy.sh` 用 `uname -s` 自动识别平台：

| 平台 | 命令 | 实际实现 |
|------|------|----------|
| Windows PowerShell | `.\deploy.cmd -Action ...` | `scripts/deploy-wife-legal-skills.ps1` |
| Windows Git Bash / MSYS2 / Cygwin | `./deploy.sh ...` | 自动转调 PowerShell 实现 |
| macOS / Linux | `./deploy.sh ...` | `scripts/deploy-wife-legal-skills.sh` |
| 其他系统 | `./deploy.sh ...` | 报错并提示支持的平台 |

两个实现的动作、参数、菜单编号完全一致；分类编号按 `catalog.tsv` 原始顺序，Windows 与 macOS 看到的编号相同。

默认技能库根目录：

- Windows：`D:\Git\ai-skills\wife-legal`（没有 D 盘则用户目录下 `Git\ai-skills\wife-legal`）
- macOS / Linux：`~/Git/ai-skills/wife-legal`

## 常用命令

```bash
# 看分类与仓库清单
./deploy.sh --action list

# 交互式选择（输入编号 / 分类名 / 仓库名，直接回车=全部但不含大型库）
./deploy.sh --action install

# 按分类装
./deploy.sh --action install --category 合同与商事 --category 劳动与用工

# 按仓库装
./deploy.sh --action install --repo Legal-Skills-Chinese --repo cn-labor-law-skills

# 全部（大型库默认跳过）
./deploy.sh --action install --all
./deploy.sh --action install --all --include-large

# 启用到某个项目（只启用选中的）
./deploy.sh --action enable --repo cn-labor-law-skills --project ~/work/case-2026

# 停用 / 更新 / 状态
./deploy.sh --action disable --repo cn-labor-law-skills --project ~/work/case-2026
./deploy.sh --action update
./deploy.sh --action status
```

Windows 把 `./deploy.sh --action X` 换成 `.\deploy.cmd -Action X`，`--category` / `--repo` / `--project` 换成 `-Category` / `-Repo` / `-Project` 即可。

## 选型建议

1. **国内民商事主力**：`Legal-Skills-Chinese`（清华智能法治研究院，76 个中文法律技能，大陆成文法、律师手写验证，覆盖合同审查、起诉状、证据梳理、类案检索、劳动争议、股权协议、合规自查、风险分级）。纯 SKILL.md，可直接导入。
2. **沉淀个人办案 SOP**：`legal-skills`（执业律师维护的实战工作流：咨询接待、合同红评、诉讼文书、刑事辩护、尽调底稿、法规检索，支持自定义律所模板与审查标准）。
3. **诉讼律师**：`lawyerDU`（诉讼可视化、案件报告、证据目录、办案日志、文书生成，输出可同步案件云）+ `cn-litigation-toolkit`。
4. **跨境业务**：`claude-for-legal`（Anthropic 官方，英美法，需自行替换法条库）+ `awesome-legal-skills`（按需挑选单条 SKILL.md，不要整仓导入）。
5. **企业法务 / 合规**：`Claude-Skills-Governance-Risk-and-Compliance` + `SOE-Legal-Checker`（国企合规）+ `qulv-china-legal-counsel-skill`。
6. **劳动仲裁**：`cn-labor-law-skills` + `worker-rights-cn`（入职、解除、竞业、加班费、工伤、仲裁流程）。
7. **域外法**：`AI-Skills-German-Law`（德国法 319 个技能）、`commercial-legal-pl`（波兰商事法）。

## 大型库注意事项

| 仓库 | SKILL.md 数量 | 处理方式 |
|------|------|------|
| legal-skills-open | 20295 | 默认不装不启用；确需使用追加 `--include-large` |
| mini-claude-for-legal | 982 | 同上 |
| awesome-legal-skills | 281 | 同上；实际更推荐按需挑单条技能 |

技能数过多会显著拖慢 IDE 的技能索引，也是脚本默认跳过它们的原因。

## MCP 配置（按需读取，不导入也能用）

把下面内容合并进项目的 `.trae/mcp.json`（或全局 MCP 配置），重启会话后生效：

```json
{
  "mcpServers": {
    "legal-skills": {
      "command": "npx",
      "args": [
        "-y", "@modelcontextprotocol/server-filesystem",
        "D:\\Git\\ai-skills\\wife-legal"
      ]
    }
  }
}
```

macOS / Linux 把路径改成 `"/Users/<用户名>/Git/ai-skills/wife-legal"`（或 `/home/<用户名>/...`）。配置后 Agent 可按需浏览、读取技能库里的任意 SKILL.md。

## 仓库收录规则

1. 在 `aukodeng-skill` 组织下 fork 目标仓；
2. 打上 topic `wife-legal`；
3. 在 `catalog.tsv` 增加一行（仓库名、分类、上游地址、是否大型库、技能数、说明）；
4. 提交并推送后，各机器执行 `--action update` 即可看到新仓。

本仓自身不打 `wife-legal` 标签，避免被脚本当成技能仓收录。
